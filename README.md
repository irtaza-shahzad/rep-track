# Workout Tracking App

A cross-platform mobile application for logging workouts, tracking progress, and maintaining fitness consistency.
Built with React Native (frontend) and FastAPI (backend) using PostgreSQL with SQLAlchemy ORM.

## Overview

This project provides free access to core workout tracking features commonly locked behind paywalls in commercial apps.
Users can log workouts, browse exercise libraries, create custom exercises, view progress graphs, export data, and receive reminders for workout consistency.

## Tech Stack

- Frontend: React Native
- Backend: FastAPI (Python)
- Database: PostgreSQL
- ORM: SQLAlchemy

## Features

- Live workout logging
- Exercise library (predefined and custom)
- Workout templates
- Historical workout tracking
- Graphical progress visualization
- Data export (CSV, PDF)
- Streaks and reminders
- Secure user authentication (signup, login)
